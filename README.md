# Electrical-Measurement-and-Instrumentation-EE288-Lab-Activities-
IoT Real-Time Sensor Dashboard

A real-time IoT monitoring system that collects sensor data and displays it on a web dashboard.
The project demonstrates how sensor values can be transmitted and visualized for easy monitoring.
The system enables users to monitor sensor values remotely through a simple and responsive interface.

Features

* Real-time sensor data monitoring
* Temperature and humidity display
* Web-based dashboard
* MQTT communication between the device and dashboard

Technologies

Arduino/ESP • MQTT • HTML • CSS • JavaScript

Project Overview

This project was developed as a group project to demonstrate the use of IoT and MQTT technology for real-time sensordata communication and visualization.
